# Fantasy Premier League - AI Workflow & Instructions

## ความต้องการของผู้ใช้ (User Requirements)
1. **การดึงข้อมูลรายสัปดาห์:** ผู้ใช้ต้องการให้สรุปคะแนนแต่ละลีก (ORCA Fantasy และ CCC Season III) หลังจบ Gameweek ในทุกๆ สัปดาห์
2. **รูปแบบการสรุป (Format):**
   - **อันดับรายสัปดาห์ (Weekly Points):** ต้องแสดงคะแนนดิบ (Gross), คะแนนสุทธิ (Net) และต้องโชว์แต้มที่ถูกหักจากการเปลี่ยนตัวเกินโควต้า (Transfer Hits) อย่างชัดเจน
   - **อันดับคะแนนรวม (Overall Points):** จัดอันดับตามคะแนนรวมทั้งหมด
3. **การตรวจสอบสถานะ Gameweek:** ระบบต้องมีความฉลาดพอที่จะเช็คว่า Gameweek นั้นจบลง "อย่างเป็นทางการ" แล้วหรือยัง (เตะครบ และคำนวณคะแนนโบนัสเสร็จสมบูรณ์ 100%) โดยเช็คจากสถานะ `finished` และ `data_checked` ของ API ก่อนที่จะสรุปผลเสมอ เพื่อป้องกันปัญหาช่วง Double Gameweek หรือสัปดาห์ที่มีแข่งตกค้าง
4. **การรันอัตโนมัติ:** ได้ตั้ง Cron Job อัตโนมัติไว้ให้รันโค้ดเช็คข้อมูลทุกวันเวลา 06:00 น. เช้า (เวลาไทย) หากคอมพิวเตอร์ปิดอยู่ ให้ข้ามไปก่อน (รอหาวิธีที่เหมาะสมในอนาคต หรือใช้วิธีพิมพ์เรียก On-demand แทน)
